# Retail-Sales-Data-Analysis

## Project Overview
This is a beginner-level Retail Sales Data Analysis project using MySQL and Microsoft Excel 2019.

## Tools Used
- MySQL
- Microsoft Excel 2019

## Dataset
The dataset contains retail sales information, including:
- Order ID
- Order Date
- Customer Name
- Product Name
- Category
- Quantity
- Unit Price
- Region

## Project Objectives
- Calculate total revenue.
- Analyze category-wise sales.
- Analyze region-wise sales.
- Identify top-selling products.
- Calculate customer-wise spending.
- Analyze monthly sales trends.
- Create Pivot Tables and charts in Excel.

## Project Files
- Retail_Sales.csv – Sales dataset
- SQL_Queries.sql – SQL analysis queries
- Retail_Sales_Analysis.xlsx – Excel analysis and reports
- Dashboard.png – Final dashboard (when completed)

## Project Status
Beginner portfolio project. Analysis and dashboard work will be updated as completed.
